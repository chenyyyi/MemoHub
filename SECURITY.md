# Security Policy

## Supported Versions

Currently supported versions for security updates:

| Version | Supported          |
|---------|--------------------|
| 0.3.x   | ✅ Yes              |
| < 0.2   | ❌ No               |

## Reporting a Vulnerability

Please report security vulnerabilities to the project maintainers. Do not open public issues for security problems.

Send details to: [chenyyyi](https://github.com/chenyyyi)

We will acknowledge your report within 48 hours and provide a more detailed response within 72 hours.

## Data Security

MemoHub is a local-first application:
- All data is stored locally on your device (`%LOCALAPPDATA%\MemoHub\` on Windows)
- API keys are stored in plain text in local config files — keep your device secure
- No telemetry or analytics are collected
- The app does not communicate with any servers other than the AI API you configure
